# V1.1 食指繪圖測試指南

## 建置

1. 在 GitHub Desktop 切換到 `agent/fingertip-draw-v1`。
2. 用 Visual Studio 開啟 `CSharp_YoloOnnx.sln`。
3. 將方案平台選成 `x64`。
4. 先還原 NuGet 套件，再建置並執行。
5. 確認輸出目錄內有
   `Models/hand_landmark_full.tflite`。

## 操作

1. 連接相機並開始擷取畫面。
2. 確認視窗標題為 `CSharp YOLO ONNX V1.1`。
3. 將任一手的手掌朝向相機，張開至少三根手指並保持 0.6 秒；不必先把手舉過肩膀。
4. 看見開始成功提示後收起其他手指，再以同一隻手的食指在空中畫圖。
5. 繪圖期間會鎖定開始時選用的手，另一隻手不會搶走軌跡。
6. 再次將食指與拇指捏合並保持 0.6 秒完成；橘色圓弧會顯示進度。
7. 若中途放開，完成動作會取消並可繼續畫圖。
8. 也可將目前繪圖手的手腕放回胸前並停留 0.8 秒，作為備用完成方式。
9. 完成後到程式輸出目錄的 `Drawings` 資料夾確認 PNG 與 JSON。
10. 可先按「選擇比對圖」，完成繪圖後會顯示相似度。

## 預期結果

- 左手或右手都能以張掌 0.6 秒開始，不再要求手腕高於肩膀。
- 張掌開始與捏合完成使用不同動作，畫面以綠色／橘色圓弧分別提示進度。
- 取像期間人物方框與骨架會持續即時更新，不需要停止取像才顯示。
- 左上角會顯示 `LIVE | YOLO persons: N`；有人入鏡時 `N` 應至少為 1。
- 黃色軌跡跟隨開始時所選手的食指，而不是手腕。
- 捏合時暫停畫線，保持 0.6 秒後自動儲存及比對。
- 指尖信心門檻調整為 35%；短暫辨識不到時，標記最多保留 0.4 秒。
- 指尖辨識不到超過 0.5 秒後，下一段會從新筆畫開始。
- JSON 內包含 `strokeCount` 與 `strokeStartIndices`。

## 常見狀況

- 顯示「指尖模型未載入」：確認模型已複製到執行檔旁的 `Models` 資料夾，並確認 NuGet 套件已還原。
- 一直顯示「正在尋找左手／右手食指」：讓目前繪圖手的手掌與食指面向相機，並確保手腕與手肘都在畫面內。
- 張掌沒有開始：讓手掌正面朝向相機，至少把食指、中指、無名指、小指中的三根伸直。
- 指尖標記跳動：先增加現場光線並讓手部在畫面中更大；之後再依相機距離微調裁切範圍。
