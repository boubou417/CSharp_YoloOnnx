# V1.2 魔法動畫測試指南

## 建置

1. 在 GitHub Desktop 切換到 `agent/fingertip-draw-v1` 並執行 Pull。
2. 用 Visual Studio 開啟 `CSharp_YoloOnnx.sln`。
3. 將方案平台選成 `x64`，還原 NuGet 套件後重新建置。
4. 確認執行檔旁有 `Models/hand_landmark_full.tflite`。
5. 確認執行檔旁有 `Assets/magic-cast-test.gif`。
6. 確認執行檔旁有 `Templates/template.png`。

## 操作

1. 開始擷取相機畫面，確認標題為 `CSharp YOLO ONNX V1.2`。
2. 左右任一手張掌保持 0.6 秒開始。
3. 收起其他手指，以同一隻手的食指繪製任意有效軌跡。
   五角星建議順序為：上 → 左下 → 右上 → 左上 → 右下 → 上。
4. 食指與拇指捏合保持 0.6 秒完成。
5. 軌跡成功儲存後，畫面中央應播放約 2 秒的藍紫色魔法陣。
6. 畫面下方應顯示「形狀相似度 0.0～100.0 分」。
7. 動畫結束後，程式會自動回到等待張掌狀態。

## 預期結果

- 動畫疊加在即時相機畫面上，不會取代人物骨架、方框或相機影像。
- 動畫播放期間仍維持相機取像，不額外執行影像辨識模型。
- 軌跡少於最低點數時顯示「軌跡太短」，且不播放動畫。
- 動畫檔載入失敗時仍可完成軌跡儲存，不會使程式停止。
- 本版不檢查圖形是否正確，任何有效軌跡完成後都會播放動畫。
- 程式啟動時會自動載入五角星範本，完成後狀態列會顯示目前的圖片相似度分數。
- 大型分數面板會顯示約 2.5 秒，分數同時寫入 `Drawings` 內對應的 JSON。
- 建議先各畫 5 次「接近標準的星星」與「明顯錯誤的圖形」，記錄分數後再決定動畫門檻。
- 繪圖時將食指與拇指保持分開並移動右手，單幀誤判不應再讓食指圓圈跳到拇指。
- 真正捏合時需先連續確認約 0.18 秒，總共保持 0.6 秒後仍應正常完成。
- 若預確認期間放開，橘色進度會取消，下一段軌跡會從新筆畫開始，避免錯誤跨線。
- 在畫面近處畫大星星、遠處畫小星星，兩者都會先等比例縮放並置中，原始大小不計分。
- 比對只看最後線條形狀，不比較從哪個頂點開始、繪製方向或經過頂點的順序。
- 程式會在 -8° 到 +8° 內校正小幅傾斜，並以 10 px 容許距離計算最高分。
