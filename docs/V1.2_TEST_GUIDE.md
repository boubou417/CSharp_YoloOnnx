# V1.2 魔法動畫測試指南

## 建置

1. 在 GitHub Desktop 切換到 `agent/fingertip-draw-v1` 並執行 Pull。
2. 用 Visual Studio 開啟 `CSharp_YoloOnnx.sln`。
3. 將方案平台選成 `x64`，還原 NuGet 套件後重新建置。
4. 確認執行檔旁有 `Models/hand_landmark_full.tflite`。
5. 確認執行檔旁有 `Assets/magic-cast-test.gif`。

## 操作

1. 開始擷取相機畫面，確認標題為 `CSharp YOLO ONNX V1.2`。
2. 左右任一手張掌保持 0.6 秒開始。
3. 收起其他手指，以同一隻手的食指繪製任意有效軌跡。
4. 食指與拇指捏合保持 0.6 秒完成。
5. 軌跡成功儲存後，畫面中央應播放約 2 秒的藍紫色魔法陣。
6. 動畫結束後，程式會自動回到等待張掌狀態。

## 預期結果

- 動畫疊加在即時相機畫面上，不會取代人物骨架、方框或相機影像。
- 動畫播放期間仍維持相機取像，不額外執行影像辨識模型。
- 軌跡少於最低點數時顯示「軌跡太短」，且不播放動畫。
- 動畫檔載入失敗時仍可完成軌跡儲存，不會使程式停止。
- 本版不檢查圖形是否正確，任何有效軌跡完成後都會播放動畫。
